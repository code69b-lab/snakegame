# 🐍 지렁이 게임 (Snake Game)

웹 브라우저와 파이썬(Pygame) 환경 모두 지원하는 클래식 지렁이 게임입니다.

---

## 🌐 1. 웹 브라우저에서 플레이하기 (설치 불필요)
- **온라인 바로 접속**: [https://code69b-lab.github.io/snakegame/](https://code69b-lab.github.io/snakegame/)
- 또는 로컬에서 `index.html` 파일을 더블 클릭하여 실행할 수 있습니다.
- **조작**: 방향키(`↑`, `↓`, `←`, `→`) 또는 `W`, `A`, `S`, `D` / 화면 가상 버튼 터치

---

## 💻 2. 파이썬(Pygame)으로 실행하기

### 필수 라이브러리 설치
```bash
pip install pygame
```

### 게임 실행
```bash
python snake.py
```

### 파이썬 조작 키
- **방향 이동**: 방향키(`↑`, `↓`, `←`, `→`) 또는 `W`, `A`, `S`, `D`
- **게임 오버 시**: 
  - `C`: 다시 시작 (Continue)
  - `Q`: 게임 종료 (Quit)

---

## ✨ 기능 특징
- **점수 및 스피드**: 먹이를 먹을 때마다 길이가 늘어나고 속도가 점점 증가합니다.
- **다크 테마 디자인**: 깔끔한 UI와 직관적인 조작감을 제공합니다.
