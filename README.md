# 🐍 지렁이 게임 (Snake Game)

웹 브라우저에서 바로 즐길 수 있는 클래식 지렁이 게임입니다. 별도의 설치 없이 HTML 파일 하나로 실행됩니다.

## 🎮 게임 플레이 방법
- `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)에서 실행합니다.
- 화면의 **게임 시작** 버튼을 누르거나 **Space / Enter** 키를 누릅니다.
- **조작 키**:
  - **키보드**: 방향키(`↑`, `↓`, `←`, `→`) 또는 `W`, `A`, `S`, `D`
  - **화면 터치/마우스**: 하단의 가상 방향 버튼(`▲`, `◀`, `▼`, `▶`) 클릭

## ✨ 주요 기능
- **점수 및 속도 증가**: 빨간 먹이를 먹을 때마다 몸길이가 늘어나고 속도가 조금씩 빨라집니다.
- **최고 점수 기록**: 웹 브라우저 로컬 저장소(LocalStorage)를 통해 최고 점수가 자동 보관됩니다.
- **반응형 디자인**: PC 키보드 환경과 모바일/태블릿 화면 모두 지원합니다.
